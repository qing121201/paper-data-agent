# AI 开发任务与所有权

本项目保留六个长期开发任务。任务是协作边界，不是运行时进程，也不是把产品拆成六个独立程序。

## 1. 产品架构与集成

职责：产品路线、模块接口、目录规范、跨模块决策、版本集成、发布前验收。

主要所有权：`AGENTS.md`、`README.md`、`docs/`、打包/CI/发布配置和跨模块兼容层。

## 2. 桌面端 UI 与交互

职责：信息架构、窗口自适应、设计系统、主题、可访问性、状态反馈和 GUI 测试。

主要所有权：`paper_data_agent/ui/`、过渡期的 `gui.py`、`ui_settings.py`、`markdown_render.py` 和 GUI 测试。

不负责：OpenAlex 排序、PDF 解析、Agent 规划或 PPT 生成算法。

## 3. 论文库与检索

职责：本地/网页论文导入、元数据、PDF 解析、全文分块、去重、BM25、Embedding、混合检索和阅读单元。

主要所有权：`library.py`、`core.py` 的数据与检索部分、`embeddings.py`、`reading.py` 和相应测试。

## 4. Agent 与科研工作流

职责：模型配置、LLM 客户端、任务协商、有界规划、工具/Skill 编排、证据回答、检查点和恢复。

主要所有权：`workflow.py`、`llm.py`、`skills.py`、`providers.py`、`config.py` 和 Agent 入口。

## 5. 在线发现与推荐

职责：OpenAlex 查询、主题扩展、订阅、候选合并、时间/引用/相关性排序、外链验证和推荐入库接线。

主要所有权：`discovery.py`、`web_sources.py` 的公开来源探测、在线搜索适配器和相应测试。

## 6. PPT 与科研可视化

职责：论文图表定位、裁剪、受控重绘、PPT 规格、生成、预览、逐页修改和质量检查。

主要所有权：`paper_visuals.py`、`presentation_workspace.py`、PPT 界面、PowerPoint 脚本和相应测试。

## 共享热点与协作规则

`gui.py`、`adapters.py`、`core.py` 当前跨越多个职责，是第一阶段重构重点。在完成拆分前：

- 只有“产品架构与集成”任务执行结构移动。
- 领域任务提出接口需求，不并行重写共享热点。
- 一个改动涉及两个所有权域时，先写清调用方、被调用方、输入输出和测试，再决定由谁实现。
- 并行编码必须使用独立 worktree/分支；当前同目录任务默认串行。

## 任务启动模板

新任务开场应包含：目标、负责目录、禁止修改目录、接口依赖、验收测试、是否允许联网/写文件。任务结束应报告：修改文件、行为变化、测试结果、遗留风险和需要集成的提交。
