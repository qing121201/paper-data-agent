# 论文 Data Agent 产品定义

## 产品目标

论文 Data Agent 是一个本地优先的科研阅读桌面应用。用户可以建立多个独立论文库，导入本地 PDF 或公开论文，完成检索、阅读、证据问答、在线发现、综述辅助、图表处理和组会 PPT 制作。

产品需要让用户始终知道：使用了哪些论文、读到了什么范围、证据来自哪一页、哪些内容是模型生成、哪些动作会访问网络或写入文件。

## 目标用户

- 需要管理多个课题论文的学生和研究人员。
- 希望使用国内外 OpenAI 兼容模型 API，但不愿默认上传整个论文库的用户。
- 需要从论文证据进一步生成综述草稿、研究脉络、科研图和汇报 PPT 的用户。

## 核心用户流程

1. 在首页按研究方向、期刊或会议发现近期论文。
2. 将公开全文或本地 PDF 加入某个独立论文库。
3. 建立关键词与语义混合索引。
4. 与 Agent 协商任务范围和阅读深度。
5. 查看带论文、路径、页码和阅读覆盖范围的回答。
6. 继续生成可核验的综述、图表、思维导图或 PPT，并逐页修改。

## 产品原则

- **本地优先**：论文库、索引和会话默认保存在用户电脑。
- **证据优先**：回答必须区分论文原文、元数据和模型推断。
- **渐进授权**：只对必要文件和公开网站执行受控工具。
- **可恢复**：耗时任务保存检查点，失败后可继续。
- **可替换模型**：模型供应商通过配置接入，不把核心功能绑定到单一 API。
- **模块化演进**：先保持一个可发布的桌面单体；只有明确出现多人并发、云同步或服务化需求时才拆服务。

## 当前版本范围

- Windows 本地 GUI。
- 多论文库、本地 PDF 与公开网页导入。
- BM25 与可选本地多语言 Embedding 混合检索。
- DeepSeek、Kimi、千问、智谱及 OpenAI 兼容接口配置。
- 有界多步骤科研 Agent、阅读深度协商、检查点恢复。
- OpenAlex 论文发现、排序、链接验证与入库。
- 原文图截取、受控科研图生成、PPT 生成和逐页修改。

## 当前非目标

- 默认上传论文或聊天训练共享模型。
- 绕过付费墙、登录、验证码或版权限制。
- 把桌面应用直接暴露为公网服务。
- 在缺少证据时自动声称已阅读全文或已验证科研结论。
- 同时支持多人云协作、账户体系和跨设备同步。

## 产品化缺口

- 源码与用户运行时数据仍位于同一工作区；迁移需要保留旧数据并由用户确认。
- GUI 和工具适配器仍有过大文件，正在做无行为模块拆分。
- 尚无正式安装包、自动更新、崩溃日志和数据迁移版本机制。
- 第三方 Skill 目前以固定副本随仓库保存，后续需要形成最小运行清单和升级流程。
